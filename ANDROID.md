# Разгром для Android
Офлайн-ежедневник для студентов и работающих специалистов. В версии 2.0 экраны, хранение задач и обработка системных напоминаний написаны на Python 3.12. Chaquopy связывает Python с Android SDK. Gradle генерирует платформенные классы Activity и BroadcastReceiver при сборке.

## Установка и первый запуск
1. Откройте [релизы проекта](https://github.com/g0d4bid/projectRazgrom/releases) и скачайте APK версии 2.0. Требуется Android 8.0+ с 64-разрядным ARM или x86.
2. Откройте файл на телефоне и разрешите установку из выбранного источника. На Android 13+ разрешите уведомления при запуске.
3. Нажмите «+ Добавить задачу», введите название и сохраните. По умолчанию задача попадает на выбранную дату со средним приоритетом. Нажатие на название открывает форму редактирования и удаления, флажок меняет статус.
4. Выберите «Неделя» и нажмите на день со счётчиком задач. В настройках можно отключить напоминания или выбрать смещение 0, 5, 15, 30 либо 60 минут.
5. На Android 12+ откройте «Настройки» → «Разрешить точные сигналы». При отсутствии разрешения ОС может отложить доставку. Напоминание о будущем деле планируется при сохранении задачи с указанным временем.

Приложение имеет отдельный идентификатор ru.razgrom.diary.python и устанавливается рядом с учебной версией 1.0. Задачи версий хранятся отдельно. Удаление приложения стирает его базу.

## Состав проекта
- android/src/main/python/diary_ui.py — экраны дня, недели, задачи и настроек.
- pr3_prototype/razgrom_core.py и schema.sql — общие для APK и тестов классы TaskRepository и ReminderPlanner, схема SQLite.
- android/src/main/python/diary_alarms.py — AlarmManager, системные уведомления, восстановление расписания после перезагрузки.
- docs/ — четыре исходных отчёта и [результаты повторной проверки](docs/ACCEPTANCE.md).
- tests/android_acceptance.py — сквозные проверки установленного APK на выделенном эмуляторе. Сценарий меняет сетевые настройки эмулятора.

## Сборка и тестирование
Требуются JDK 17, Gradle 8.9, Python 3.12 и Android SDK Platform 35. Из корня проекта выполните:

```
python -m unittest discover -s pr3_prototype -v
gradle :android:assembleDebug
```

Укажите ANDROID_HOME и JAVA_HOME. При нескольких интерпретаторах переменная BUILD_PYTHON задаёт путь к Python 3.12. Демонстрационный подписанный APK появляется в android/build/outputs/apk/debug/android-debug.apk. Для проверки на чистом эмуляторе API 30 установите файл командой adb install, затем запустите python tests/android_acceptance.py. Конфигурация GitHub Actions повторяет сборку, прикладывает APK и выполняет тот же сценарий.
