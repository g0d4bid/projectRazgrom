# Разгром
Офлайн-ежедневник для Android 8.0 и новее. Откройте раздел Releases и скачайте Razgrom-1.0.apk. Установите APK и разрешите уведомления. Для точной доставки на Android 12 и новее включите точные сигналы по предложению приложения.
## Работа с задачами
Добавьте дело, выберите дату, время и приоритет. Нажатие на название открывает редактирование и удаление. Флажок отмечает выполнение. Экраны «Сегодня» и «Неделя» читают задачи из SQLite. Разрешение на интернет приложению не требуется.
## Материалы проекта
docs/ содержит четыре отчёта, pr3_prototype/ — исходный прототип Python и тесты. Исторические результаты ПР4 относятся к этому прототипу. Android-клиент в android/ реализован на Java с SQLiteOpenHelper и AlarmManager. В практической работе 3 проектировался клиент на Flutter. В демонстрационный APK входят нативные экраны.
## Проверки и сборка
Из корня запустите `python -m unittest discover -s pr3_prototype -v`. CI отдельно проверяет класс валидации Android, собирает и проверяет подпись APK. Для локальной сборки нужны JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. Укажите JAVA_HOME и ANDROID_HOME, затем выполните `python build_apk.py`. Результат появится в dist/.
Каждая демонстрационная сборка подписывается временным ключом. Для установки другой сборки поверх существующей требуется та же подпись. Удаление приложения очищает локальные задачи.
## Проверка на телефоне
Создайте дело на минуту вперёд, сверните приложение и дождитесь уведомления. Повторите с отменой и с переносом напоминания. Перезапустите приложение и проверьте сохранённый статус. Фактический результат зависит от разрешений и энергосбережения устройства.
